# ============================================================================
# LISTA DE CANDIDATOS A PROVEEDOR — este es el único archivo que hay que
# tocar para intentar sumar un proveedor nuevo. NO requiere programar nada.
#
# Formato: un dominio por línea (sin "https://", sin rutas), opcionalmente
# con un comentario después de # indicando el sector.
#
# Cómo se usa:
#   1. Agrega el dominio de la tienda del proveedor nuevo aquí abajo.
#   2. Corre:  python -m src.discover
#   3. El sistema prueba automáticamente si es una tienda Shopify o
#      WooCommerce (las dos plataformas más comunes en este sector en
#      Colombia). Si lo es, se auto-registra en config/providers_auto.yaml
#      con moneda detectada y queda activo para la próxima corrida diaria
#      — SIN que nadie tenga que escribir código ni YAML a mano.
#   4. Si el dominio no es Shopify ni WooCommerce, discover.py lo deja
#      anotado como "sin clasificar" en el reporte — esos sí necesitan
#      investigación manual (selectores CSS o una API a medida), igual
#      que se hizo con GVS, SYSCOM, SAT Store, etc.
#
# Puedes correr esto las veces que quieras; no duplica proveedores ya
# registrados (se identifican por dominio).
# ============================================================================
